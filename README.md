# Saffron & Hearth — Restaurant Website

An interactive restaurant website featuring table time-slot reservations, menu pre-ordering, and a live host desk call & callback concierge.

## Features
- **Interactive Table & Time-Slot Booking (`#booking-section`)**: Select dining date, party size, dining room zone/table, and available lunch/dinner time slots with instant booking pass confirmation and `.ics` calendar export.
- **Interactive Menu & Pre-Order Tray (`#menu-section`)**: Filter seasonal dishes by category, dietary tags, or search query, and attach pre-selected dishes directly to your table reservation.
- **Host Desk Call & Callback Hub (`#call-section`)**: Direct one-click `tel:` calling, department extensions, 2-minute live host callback countdown tracker, and an interactive web voice concierge simulator.

## Running Locally
Open `index.html` in any modern web browser.
